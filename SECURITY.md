# Security Policy

## Supported Versions

We provide security patches and vulnerability updates for the following releases:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The `blehh` engineering team takes the security of our libraries and services very seriously. If you identify a potential vulnerability or security flaw, please follow responsible disclosure practices:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the security contact: `sameer3sn7@gmail.com` with the subject:
   `[SECURITY] Vulnerability Report: blehh`
3. Provide detailed steps to reproduce the vulnerability, including:
   - Impact assessment
   - Proof of Concept (PoC) code
   - Affected versions and environments

## Response Timeline

- **Initial Acknowledgement**: Within 24 to 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Remediation & Advisory**: We coordinate coordinated disclosure and release patches promptly via GitHub Security Advisories.
